## 1. 근거 1 — "개별사용료는 개인 의지가 반영된 주관적 사용량"

### 1-1. 원본 데이터 스키마 근거

`관리비.csv` 원본 컬럼 순서를 보면, 관리비는 애초에 두 개의 상위 합계 항목 아래로 나뉜다.

```
공용관리비계
  ├─ 인건비, 제사무비, 제세공과금, 피복비, 교육훈련비, 차량유지비, 그밖의부대비용,
  │  청소비, 경비비, 소독비, 승강기유지비, 지능형네트워크유지비, 수선비, 시설유지비,
  │  안전점검비, 재해예방비, 위탁관리수수료
개별사용료계
  ├─ 난방비(공용), 난방비(전용)
  ├─ 급탕비(공용), 급탕비(전용)
  ├─ 가스사용료(공용), 가스사용료(전용)
  ├─ 전기료(공용), 전기료(전용)
  └─ 수도료(공용), 수도료(전용)
```

난방비·급탕비·전기료·수도료는 **"개별사용료계"**로 분류되어 있고, 그 안에서 다시 공용분/전용분으로 나뉜다.

- **전용(專用)**: 세대별 개별 계량기로 측정한 값 — 그 세대 거주자가 난방 온도를 몇 도로 설정하는지, 온수를 얼마나 오래 쓰는지 같은 **개별 생활 습관**에 의해 결정된다.
- **공용(共用)**: 복도·계단·공용 조명·배관 손실분 등 단지 공용부에서 발생하는 사용량 — 건물의 물리적 특성(규모, 단열 성능, 설비 노후도)에 좌우되고 개별 세대의 선택과는 무관하다.

**정량적 벤치마킹 지표의 목적이 "비슷한 조건의 단지끼리 객관적으로 비교"하는 것이라면, 전용 항목은 단지의 특성이 아니라 그 시점 입주민들의 우연한 생활 패턴 평균을 재는 셈이 되어 목적에 부합하지 않는다.**

### 1-2. 통계적 검증 (보조 근거, 결과는 엇갈림)

같은 유틸리티의 공용/전용 CV(단지별 중앙값)를 비교했다.

```python
def cv_per_complex(df, col, min_mean_q=0.10):
    g = df.groupby('단지코드')[col]
    mean, std = g.mean(), g.std()
    thresh = mean[mean > 0].quantile(min_mean_q)
    valid = mean[mean >= thresh].index
    return (std.loc[valid] / mean.loc[valid])
```

| 유틸리티 | 공용 CV | 전용 CV |
|---|---|---|
| 난방비 | 0.764 | **1.214** (전용이 더 큼 — 가설 지지) |
| 전기료 | 0.399 | **0.304** (전용이 더 작음 — 가설과 반대) |

![공용 vs 전용 비교](260902_전용4종_삭제근거_img/1_junyong_summary.png)

**정직하게 밝히면**: 난방비는 "전용이 더 들쭉날쭉하다"는 가설과 일치하지만, 전기료는 반대 방향으로 나왔다. 즉 CV만으로는 "개별사용료가 항상 더 주관적·불규칙하다"는 명제를 일관되게 증명하지 못한다. **이 근거의 진짜 힘은 통계적 변동성이 아니라 1-1절의 정의 자체(무엇을 측정한 값인가)에 있다** — 전기료(전용)의 CV가 낮다고 해서 그 값이 "단지의 객관적 특성"이 되는 것은 아니며, 여전히 세대별 실사용량이라는 본질은 변하지 않는다.

## 2. 근거 2 — "0값·음수가 많아 큰 잔차 발생"

for col in JUNYONG4:

### 2-2. 잔차 폭발 재현 — 실제로 지표를 만들어보면

"단지 평균 ÷ 전체 평균 × 100"이라는 가장 단순한 정규화 지수를 0값 없는 항목(`인건비`, 참고용)과 0값이 많은 항목(`난방비(전용)`, `급탕비(전용)`)에 각각 적용했다.

```python
def naive_index(df, col):
    m = df.groupby('단지코드')[col].mean()
    return (m / m.mean()) * 100
```

| 항목 | 표준편차 | \|지수-100\|>200인 단지 수 |
|---|---|---|
| 인건비 (참고) | 37.5 | 7개 (0.3%) |
| 난방비(전용) | **173.1** | **397개 (17.9%)** |
| 급탕비(전용) | **155.9** | **396개 (17.8%)** |

![0값 항목의 잔차 폭발](260902_전용4종_삭제근거_img/2_residual_demo.png)

인건비는 100 근처로 촘촘히 모인 정규분포에 가까운 반면, 난방비(전용)·급탕비(전용)는 **0에 거대한 스파이크**(그 항목이 없는 단지들)가 생기고 나머지는 200~500까지 넓게 퍼지는 기형적인 분포가 된다. 표준편차가 인건비의 4.1~4.6배에 달한다 — "큰 잔차를 발생시킨다"는 근거 2가 정량적으로 확인된다.

## 3. 근거 3 — "정량 지표에서는 배제, 예측모델에서는 사용 가능"

이 방향은 이미 코드에 반영돼 있다. `per_df`에서 컬럼을 삭제하는 것이 아니라, 총점 계산용 리스트에서만 뺐다.

```python
G2_ITEMS = ['난방비(공용)_perm2', '전기료(공용)_perm2']
EXCLUDED_G2_JUNYONG = ['난방비(전용)_perm2', '급탕비(전용)_perm2',
                       '전기료(전용)_perm2', '수도료(전용)_perm2']  # (전용) 4종 — 총점에서 제외, 컬럼은 per_df에 유지

COST_SCORE_ITEMS = G1_ITEMS + G2_ITEMS + G3_ITEMS + G4_ITEMS + ['기타소액계_perm2']
per_df['관리비합계_perm2'] = per_df[COST_SCORE_ITEMS].sum(axis=1)   # 전용 4종은 여기 포함 안 됨
```

`per_df.columns`에는 `난방비(전용)_perm2` 등 4개 컬럼이 원본 그대로 남아 있다(검증: 노트북 재실행 후 `'난방비(전용)_perm2' in per_df.columns` → `True`). 따라서 이후 회귀/머신러닝 기반 예측 모델을 만들 때는 이 4개 컬럼을 피처로 그대로 활용할 수 있다 — 정량 지표(단지 간 공정 비교용 총점)와 예측 모델(관리비 총액 추정)은 목적이 다르므로 같은 원본 데이터에 대해 다른 컬럼 선택을 적용하는 것이 합리적이다.

## 4. 결론

세 가지 근거 모두 실제 데이터로 뒷받침된다.

1. **정의상 문제**: 전용 항목은 세대별 개별 계량값으로, 단지의 객관적 특성이 아니라 그 시점 입주민의 생활 패턴을 반영한다(스키마 근거는 강함, CV 비교는 엇갈림 — 정의가 핵심 근거).
2. **데이터 품질 문제**: 0값이 9~78%에 달해 이를 그대로 정규화하면 표준편차가 4배 이상 커지는 기형적 지수가 만들어진다(강한 근거).
3. **용도 분리**: 이미 코드로 구현됨 — `per_df` 원본은 유지, 총점 계산에서만 제외.
