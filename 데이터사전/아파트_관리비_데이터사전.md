# 아파트 관리비 분석 데이터 사전

## 1. 문서 개요

이 문서는 K-apt 원자료와 이를 정규화한 분석용 데이터의 테이블 구조, 컬럼 의미 및 사용상 주의사항을 정리한 데이터 사전이다. 현재 분석용 배포본은 `서울_균형패널_2021_2025_v1.0`이며, 원본 헤더와 실제 값의 형태, K-apt 및 KOSIS 문맥을 기준으로 설명한다.

### 현재 분석용 데이터 버전

| 항목 | 내용 |
|---|---|
| 버전 | `서울_균형패널_2021_2025_v1.0` |
| 저장 위치 | `data/서울_균형패널_2021_2025_v1.0/` |
| 기준 지역 | 서울특별시 |
| 분석 기간 | 2021년 1월~2025년 12월(60개월) |
| 최종 표본 | 2,454개 단지 |
| 월별 관측치 | 147,240행(2,454개 단지 × 60개월) |
| 원천 | K-apt 단지 기본·면적·연도별 관리비 자료 |
| 선정 기준 | 60개월 동안 `단지코드 + 발생년월`이 매월 정확히 1행 존재하고 기본정보·면적정보와 연결되는 단지 |
| 검증 기록 | `정규화_검증보고서.json` |

> 이 데이터는 매월 자료가 모두 존재하는 단지만 남긴 **균형패널**이다. 자료가 일부 누락된 단지는 제외되므로 서울 전체 단지를 그대로 대표하는 횡단면 자료로 해석하지 않는다.

### 공통 주의사항

- K-apt 파일은 1행이 안내문이고 **2행이 실제 헤더**다.
- `단지코드`는 K-apt 테이블 간 결합키로 사용한다.
- 관리비 자료의 기준키는 일반적으로 `단지코드 + 발생년월(YYYYMM)`이다.
- 날짜, 우편번호, 전화번호, 사업자등록번호는 숫자 계산 대상이 아니므로 문자열로 적재하는 것이 안전하다.
- 금액 컬럼은 원본 안내에 별도 단위가 없는 경우 원 단위로 해석하되, 활용 전 K-apt 원문/API 정의와 대조한다.
- 공란과 `0`은 의미가 다를 수 있다. 공란은 미입력·미제공, `0`은 값이 없음을 명시한 것으로 우선 구분한다.
- 분석용 CSV는 UTF-8 BOM 형식이며, 금액은 단지별 해당 월의 총액이다. 단가 비교 시 `관리비부과면적` 또는 분석 목적에 맞는 세대수로 나누어 사용한다.
- `전기차정보_미사용.csv`는 보유 자료이지만 현재 가설 검증과 예측 모델에는 사용하지 않았음을 파일명으로 표시했다.

## 2. 분석용 균형패널 테이블 관계

| 테이블 | 권장 키 | 관계 및 용도 |
|---|---|---|
| `기본정보.csv` | `단지코드` | 2,454행. 단지 식별·규모·노후도·관리방식 등을 제공하는 마스터 테이블 |
| `운영정보.csv` | `단지코드` | 2,454행. 일반관리·경비·청소·소독 운영 방식과 인력 정보 |
| `시설정보.csv` | `단지코드` | 2,454행. 건물·전기·승강기·주차·CCTV 등 시설 정보 |
| `전기차정보_미사용.csv` | `단지코드` | 2,454행. 전기차와 충전시설 정보. 현재 분석 미사용 |
| `위치정보.csv` | `단지코드` | 2,454행. 위도·경도. 새 K-apt 원본에 없어 기존 정규화 위치정보에서 최종 표본만 추출 |
| `면적정보.csv` | `단지코드 + 주거전용면적(세부)` | 13,852행. 단지별 면적 유형과 해당 세대수. 한 단지에 여러 행 존재 |
| `관리비.csv` | `단지코드 + 발생년월(YYYYMM)` | 147,240행. 공용관리비와 개별사용료의 월별 균형패널 |
| `장기수선.csv` | `단지코드 + 발생년월(YYYYMM)` | 147,240행. 장기수선충당금·잡수입의 월별 균형패널 |
| `정규화_검증보고서.json` | 해당 없음 | 기간, 필터, 원본·최종 행 수, 연결 실패 및 제외 단지를 기록한 검증 메타데이터 |

### 결합 구조

- 모든 테이블은 `단지코드`로 결합한다.
- 월별 분석은 `관리비.csv`와 `장기수선.csv`를 `단지코드 + 발생년월(YYYYMM)`로 1:1 결합한다.
- `면적정보.csv`는 단지별 면적 유형이 여러 개이므로 다른 테이블과 결합하면 행이 늘어난다. 단지 수준 분석에서는 먼저 면적별 세대수를 집계하거나 대표 면적을 정의한다.
- `기본정보.csv`, `운영정보.csv`, `시설정보.csv`, `위치정보.csv`는 `단지코드` 기준 1:1 관계다.

## 12. 적재 및 분석 권장사항

1. K-apt 3개 파일은 안내문을 제외하고 2행을 헤더로 읽는다.
2. `단지코드`, 날짜, 우편번호, 연락처, 사업자등록번호는 문자열로 우선 적재한다.
3. 면적정보는 단지당 여러 행이 정상이며 단지 기본정보와 1:N 관계다.
4. 관리비정보는 금액 컬럼의 공란과 0을 구분하고 음수 조정액을 허용한다.
5. 시장규모 통계는 월이 늘어날 때 컬럼이 증가하는 가로형이므로 세로형으로 변환한다.
6. Kenneth 파일은 아파트별 블록을 먼저 분리하고, 미정의 열의 의미를 확인한 뒤 사용한다.
7. CPI 원자료는 월·연 주기가 혼재하므로 `주기` 컬럼 없이 직접 조인하지 않는다.
8. 월 비교 시 관리비의 `발생년월`과 CPI의 `시점`을 동일한 `YYYYMM` 형식으로 표준화한다.
